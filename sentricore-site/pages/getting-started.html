Getting started

From clone to your first blocked query in about five minutes. Pick your deployment style below.

Step 1 · Get the code

git clone https://github.com/SentriCore/sentricore-dns-proxy.git
cd sentricore-dns-proxy

Step 2 · Run it

docker compose up -d
docker compose ps   # proxy + web should both be running

The compose file exposes UDP 5300 (proxy) and TCP 5000 (dashboard) and persists data/ and logs/ as volumes.

python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python run_proxy.py   # terminal 1: DNS proxy on :5300
python run_web.py     # terminal 2: dashboard on :5000

For production use gunicorn in front of the Flask app instead of run_web.py.

./install.sh
sudo systemctl enable --now sentricore-dns-proxy sentricore-dns-web
systemctl status sentricore-dns-proxy

The installer creates a venv, installs dependencies, and registers both systemd units so the proxy survives reboots.

Step 3 · Point a client at it

# Test from any machine that can reach the host:
dig @<host> -p 5300 example.com

# A blocked domain returns the sinkhole answer:
dig @<host> -p 5300 evil.example
;; ANSWER SECTION:
evil.example.  300  IN  A  0.0.0.0

To make it your network's resolver, set DHCP option 6 (or the adapter's DNS server) to <host>. Clients that hard-code port 53 can be redirected with a single iptables DNAT rule:

iptables -t nat -A PREROUTING -p udp --dport 53 -j DNAT --to-destination <host>:5300

Step 4 · Watch it work

  • Open the dashboard: http://<host>:5000
  • Scrape metrics: curl http://<host>:5000/metrics
  • Block your first custom domain: 
    export SENTRICORE_API_KEY="pick-a-long-random-secret"   # set on the server
curl -X POST http://<host>:5000/api/blocklist \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $SENTRICORE_API_KEY" \
  -d '{"domain": "ads.example-tracker.com"}'
You're protected. Queries now flow through rate limiting, caching, and blocklist screening — and every one is recorded in SQLite for the dashboard and Prometheus. Next stops: the configuration reference and the API docs.
