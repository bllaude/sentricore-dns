Every capability, in one binary-sized project

Sentricore DNS keeps the DNS path simple and the control plane honest. Here is exactly what ships today — nothing vaporware, everything in the repo.

Domain blocking

CapabilityDetail
Multiple sourcesAny number of local files or URLs in blocklist_sources, merged at load time.
Format tolerancePlain domain-per-line lists and ad-block hosts format (0.0.0.0 domain) are normalized automatically.
Hot reloadLists refresh every blocklist_update_interval seconds (default 300) with zero downtime.
SinkholingMatched queries answer 0.0.0.0 with a short TTL and are counted in sentricore_blocked_queries.
Dynamic entriesAdd/remove domains at runtime via the REST API; changes persist to SQLite.

Performance & resilience

CapabilityDetail
LRU cacheUp to 10,000 responses with configurable TTL; hits answered in single-digit milliseconds.
Token-bucket rate limitingPer-client-IP sustained QPS (default 50) plus burst allowance (default 100).
Batched persistenceQuery logs and metrics flush to SQLite on an interval (default 1 s) instead of per-query writes.
Configurable upstreamPoint at any resolver — Cloudflare, Quad9, your Pi-hole, or your enterprise forwarder.

Observability

CapabilityDetail
Web dashboardFlask app with overview page, query history, and health endpoint.
Prometheus metrics/metrics exposes total queries, blocked queries, cache hits/misses, and blocklist size.
Grafana-readyStandard counter semantics make QPS and hit-ratio expressions trivial.
File loggingStructured proxy log with configurable level for journald/file tailing.

Security posture

CapabilityDetail
API-key authWrite endpoints require X-API-Key or ?api_key= when a secret is configured.
Secure defaultsWrites are denied by default if no API key is set.
Local-first dataAll history stays in your SQLite file. No outbound telemetry, ever.
Amplification defenseRate limiting caps per-client query volume, blunting abuse from compromised hosts.

Deployment

CapabilityDetail
Docker / ComposeMulti-stage image; compose file runs proxy + web as separate services.
systemdUnit files and a Raspberry Pi installer script register both services on boot.
Bare metalPlain Python 3.11+ with dnslib, Flask, gunicorn.
CI/CDGitHub Actions run tests, lint, coverage, and publish Docker images.
