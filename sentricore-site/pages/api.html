REST API reference

The web service (default http://127.0.0.1:5000) exposes a small, boring, well-behaved JSON API for blocklist control plus human and machine observability routes.

Authentication

If SENTRICORE_API_KEY or DASHBOARD_API_KEY is set on the server, protected endpoints require the secret via either:

X-API-Key: <secret>        # preferred header
?api_key=<secret>          # query parameter fallback

Secure by default: write endpoints are rejected when no API key is configured. Set SENTRICORE_DENY_WRITES_WITHOUT_KEY=0 only if you know what you are doing.

Blocklist management

GET

/api/blocklist

List every blocked domain with its source and insertion time.

curl -H "X-API-Key: $SENTRICORE_API_KEY" \
  http://127.0.0.1:5000/api/blocklist
{
  "count": 2,
  "domains": [
    {"domain": "badsite.com", "source": "api", "added_at": "2026-03-29T10:12:44Z"},
    {"domain": "evil.com",    "source": "api", "added_at": "2026-03-29T10:13:02Z"}
  ]
}
POST

/api/blocklist

Add a domain to the blocklist. Persisted to SQLite and applied immediately.

curl -X POST http://127.0.0.1:5000/api/blocklist \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $SENTRICORE_API_KEY" \
  -d '{"domain": "malware.example"}'
{"status": "ok", "domain": "malware.example", "count": 3}
DELETE

/api/blocklist/<domain>

Remove a previously added domain.

curl -X DELETE http://127.0.0.1:5000/api/blocklist/malware.example \
  -H "X-API-Key: $SENTRICORE_API_KEY"
{"status": "ok", "removed": "malware.example", "count": 2}

Exported metrics

MetricTypeDescription
sentricore_total_queriescounterTotal DNS queries processed.
sentricore_blocked_queriescounterQueries sinkholed by blocklist match.
sentricore_cache_hitscounterAnswers served from the LRU cache.
sentricore_cache_missescounterLookups that required upstream forwarding.
sentricore_blocklist_sizegaugeCurrent number of blocked domains.

Example PromQL

rate(sentricore_total_queries[5m])                       # QPS
rate(sentricore_blocked_queries[5m])                     # blocks/sec
sentricore_cache_hits / (sentricore_cache_hits + sentricore_cache_misses)  # hit ratio
